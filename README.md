# Cricket Match Simulator

A simple command-line cricket match simulator built in Python as a small OOP practice project.

The project models a cricket match using `Match`, `Team`, and `Player` objects. Teams manage their players and scores, while the match handles innings, results, and scorecards. Player performance and match outcomes are randomized.

The main goal of the project was to practice object-oriented design, object composition, nested classes, and keeping each class and method responsible for a clear part of the program.

## Running the Project

Make sure Python is installed, then run:

```bash
python main.py
```

Enter the player names when prompted and let the match play out.
