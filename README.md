# Cricket Saga

A simple cricket match simulator built in Python, evolved from a command-line game into a Tkinter-based graphical application.

The project models a cricket match using `Match`, `Team`, and `Player` objects. Teams manage their players and scores, while the match handles ball-by-ball simulation and match results. Player performances and match outcomes are randomized.

## V2 — GUI Edition

Version 2 introduces a graphical interface using **Tkinter**, replacing the original command-line interaction.

The GUI provides:

* Main menu and match setup
* Team name selection
* Player name entry for both teams
* Ball-by-ball match simulation
* Live team scores and match events
* Sequential innings for both teams
* Final scorecard with individual player scores
* Automatic match result

The project continues to serve as an OOP practice project, while V2 also explores GUI programming, callbacks, event-driven execution, and managing application state.

## Running the Project

Make sure Python is installed, then run:

```bash
python main.py
```

Follow the prompts in the GUI to set up the teams and players, then let the match play out.
